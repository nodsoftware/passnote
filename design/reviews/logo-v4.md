# Logo v4: Kinfold

v3 (Cloister) was rejected as too religious. v4 drops the church theme.

## Name

**Kinfold** is a coined word: *kin* (your own people) + *fold* (an enclosure
for a flock, and to fold in). It means a closed circle of your own devices.
Coined names make the strongest trademarks.

| Candidate | pub.dev | Software uses found | Verdict |

| kinfold | free | none (closest: "Koinfold", investment software) | **Chosen** |

This is a web search, not a clearance. Search TMview (EUIPO plus national
registers) and the USPTO in class 9 before publishing.

## Directions

| Direction | Verdict |
| --- | --- |
| Diamond sheet mid-fold | Dropped: reads as play/rewind |
| Square loop folded from one strip | Dropped: reads as a stop icon or frame |
| Split rounded square | Dropped: generic |
| Folded corner | Dropped: reads as a document icon |
| Paper pinwheels (3 and 4 blades) | Dropped: read as a fan, a radiation sign, or a loading spinner |
| **Folded K**: one strip of paper folded into the arm and leg of a K | **Chosen** |

In the lockup the folded K *is* the first letter: **K** + "infold".

## Construction (512 grid)

- Stem: x 112–196, y 80–432 (84 wide).
- Arm: (212,318) (212,228) (360,80) (412,80) (412,112).
- Leg (the strip's underside): (226,262) (284,206) (412,432) (320,432).
- One-colour version: the leg is cut 8 pt clear of the arm, so the fold reads without a second tone.
- Wordmark: "infold", Source Sans 3 Semibold 240 pt, outlined, baseline on the base of the K.
